## Learning Philosophy

- **Understanding over memorization** — Focus on fundamental concepts and underlying principles.
- **Consistency over intensity** — Build knowledge through continuous learning.
- **Practice alongside theory** — Connect abstract ideas with practical applications.
- **Documentation and reflection** — Record insights, questions, and progress.
- **Independent exploration** — Develop the ability to investigate problems independently.
